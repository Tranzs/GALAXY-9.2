GALAXY 9.2 - GRAMMAR FORMULA

1. Tenses
- Present simple: S + V(s/es)
- Past simple: S + V2/ed
- Present perfect: S + have/has + V3/ed

2. Passive voice
- S + be + V3/ed + by O

3. Conditional sentences
- Type 1: If + present simple, S + will + V
- Type 2: If + past simple, S + would + V
